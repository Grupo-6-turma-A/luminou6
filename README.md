# Monitoramento IoT para Cultivo de Vanilla Planifolia 🌿☀️

> *Sistema de monitoramento de luminosidade em tempo real para estufas teladas outdoor (Shade House).*

---

## 📖 Sobre o Projeto
A baunilha (*Vanilla planifolia*) é uma orquídea trepadeira de alto valor comercial que exige luz filtrada para se desenvolver adequadamente. Diferente de estufas fechadas, o cultivo outdoor com tela de sombreamento está sujeito a variações constantes de luz natural[cite: 2]. 

Este projeto tem como foco evitar que o excesso ou déficit de luz comprometa a saúde foliar ou a indução floral da planta, protegendo o ciclo produtivo da cultura[cite: 2].

## 🎯 Objetivo
O desenvolvimento de um protótipo IoT para atuar na prevenção de quebras de safra[cite: 2]. O sistema realiza:
- **Captura de Dados:** Utiliza um microcontrolador Arduino Uno R3 integrado a um sensor de luminosidade (fotoresistor LDR) posicionado na altura do dossel das plantas[cite: 2].
- **Processamento e Histórico:** Os dados são enviados para um banco de dados e exibidos em formato de gráficos em uma interface web[cite: 2].
- **Alertas Inteligentes:** A plataforma web emite um alerta em tempo real sempre que a luminosidade ultrapassar a faixa ideal (10.000 a 30.000 Lux), indicando possíveis rasgos ou desgastes na tela de sombreamento[cite: 2].
